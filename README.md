# JavaScript From Scratch

A beginner-friendly repository where I learn JavaScript step by step, starting from the fundamentals and moving towards advanced concepts.

## What's inside
- Concept-wise notes and examples
- Practice problems and exercises
- Small programs to apply what I learn

- ✅ 0. Introduction to JavaScript
- ✅ 1. Variables and Declarations
- ✅ 2. Data Types
- ✅ 3. Operators
- ✅ 4. Control Flow (Conditionals)
- ✅ 5. Loops
- ✅ 6. Functions
- ✅ 7. Arrays
- ✅ 8. Objects
- ✅ 9. The DOM
- ✅ 10. Events

Build a strong JavaScript foundation for web development and land an SDE role.
